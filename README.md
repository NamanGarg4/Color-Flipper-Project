# Color-Flipper-Project
Color Flipper is a fun little web project that lets you change the background color of your page with just a click. It has two versions: a simple mode with preset colors and a hex mode that generates completely random colors. It's a great way to see how JavaScript can make web pages interactive.


What It Does
1. Click the button and watch the background color change.
2. The current color code is displayed on the screen so you can see exactly what color is applied.
3. Switch between simple colors and random hex colors with the navigation links.
4. Smooth transitions make the color changes look nice and fluid.


How It Works
1. Simple mode picks a color from a predefined list.
2. Hex mode randomly generates a hex code (like #3FA7D6) and applies it as the background.
3. The JavaScript listens for your clicks and updates the page dynamically.


Technologies Used
1. HTML for the page structure
2. CSS for styling and layout
3. JavaScript for the color-changing logic


How to Use
1. Open `index.html` for the simple color flipper or `hex.html` for the hex color version.
2. Click the "click me" button.
3. Watch the background color change and the color code update in real-time.
4. You can customize the colors in `app.js` or tweak the hex generator in `hex.js` to your liking.


File Overview
1.index.html – simple color flipper page
2. hex.html – hex color flipper page
3. app.js – JavaScript for simple colors
4. hex.js – JavaScript for hex colors
5. styles.css – styling for both pages


Why This Project
This is a simple, fun project for learning how JavaScript interacts with the DOM. It's a good starting point for beginners who want to play with colors, events, and dynamic styling.
